# BizIdea - Générateur d'Idées Business par IA

## 🚀 Description

BizIdea est une plateforme web moderne qui utilise l'intelligence artificielle pour générer des idées de business validées et adaptées au marché. La plateforme analyse les tendances et les besoins réels pour proposer des opportunités entrepreneuriales concrètes.

## ✨ Fonctionnalités

### 🧠 Générateur d'Idées Intelligent
- Génération d'idées basées sur des critères personnalisés
- Analyse du potentiel de marché
- Évaluation de la concurrence
- Estimation des coûts d'investissement

### 🤖 Mentor IA 24/7
- Assistant conversationnel intelligent
- Conseils personnalisés pour votre projet
- Réponses aux questions business
- Guidance étape par étape

### 🌍 Ciblage Géographique
- Sélection par pays/région
- Adaptation aux spécificités locales
- Analyse de marché régionale

### 📊 Analyses Détaillées
- Scores de potentiel
- Niveau de concurrence
- Investissement requis
- Tendances du marché

### 👥 Communauté
- Échange avec d'autres entrepreneurs
- Partage d'expériences
- Retours constructifs

## 🛠️ Technologies Utilisées

- **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
- **Framework CSS**: Tailwind CSS
- **Icons**: Font Awesome
- **Fonts**: Google Fonts (Inter)
- **Responsive Design**: Mobile-first approach

## 🚀 Installation et Utilisation

### Prérequis
- Navigateur web moderne
- Connexion internet (pour les CDN)

### Lancement
1. Clonez ou téléchargez le projet
2. Ouvrez `index.html` dans votre navigateur
3. Ou utilisez un serveur local pour un meilleur développement

### Serveur Local (optionnel)
```bash
# Avec Python
python -m http.server 8000

# Avec Node.js (http-server)
npx http-server

# Avec PHP
php -S localhost:8000
```

## 🎯 Utilisation

1. **Générer des Idées**:
   - Remplissez le formulaire avec vos critères
   - Sélectionnez votre localisation et secteur
   - Cliquez sur "Générer des idées"

2. **Analyser les Résultats**:
   - Consultez les idées proposées
   - Vérifiez les scores de potentiel
   - Cliquez sur "Voir l'analyse" pour plus de détails

3. **Utiliser le Mentor IA**:
   - Posez vos questions dans le chat
   - Obtenez des conseils personnalisés
   - Affinez votre stratégie business

## 🎨 Personnalisation

### Couleurs
Les couleurs principales peuvent être modifiées dans `styles.css`:
- Primaire: `#0ea5e9` (bleu)
- Secondaire: `#8b5cf6` (violet)
- Sombre: `#1e293b`
- Clair: `#f8fafc`

### Contenu
- Modifiez les idées d'exemple dans `script.js` (variable `businessIdeas`)
- Personnalisez les réponses IA dans `script.js` (variable `aiResponses`)
- Adaptez les textes dans `index.html`
